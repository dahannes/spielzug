# Requirements

What the product must do (UR), what the software does to meet it (SR), and how each SR is verified. How the tests are run: [verification](verification.md).

## Traceability in one paragraph

UR → SR → test. Every SR names its URs and its verification. Test titles carry the SR id (`[SR-32] …`), so `grep -rn "SR-32" e2e api shared src supabase/tests` finds the evidence. **The SR tables below are the traceability matrix.** Ids are stable: never renumber or reuse one. Update status and verification in the same commit as the change.

Status: ✅ done and verified · 🟡 done, verified only partly · ⏳ open.

## User requirements

| ID | Need | For |
|---|---|---|
| UR-01 | Turn the printed word list for a class test into a practice list within minutes – by photo or typed – and correct it. | parents |
| UR-02 | Practise alone: the app dictates clearly in German, the child writes on paper as in class. | child |
| UR-03 | A correction like in school: which words, which letters, what is right, and a Berichtigung to write. | child |
| UR-04 | Practice focuses on what is not secure yet; progress towards the test date is visible; start over is possible. | child, parents |
| UR-05 | A photo of the whole page or just part of it is enough – no special setup. | child, parents |
| UR-06 | The family's data is private: only the family sees it, child data stays in the EU, class material never ends up in the code. | parents |
| UR-07 | Simple, safe sign-in on the iPad and the laptop. | parents |
| UR-08 | Running costs (AI, voice, mail) stay small and predictable. | maintainer |
| UR-09 | Works on a tablet in landscape (main case) and on a phone; German and child-friendly. | child, parents |
| UR-10 | The maintainer can see what the AI reads from any sheet, to judge and improve reading. | maintainer (should) |
| UR-11 | Several children of a family practise the same word lists, each with their own progress. | child, parents |
| UR-12 | A team has several trainers with their own accounts and player profiles without accounts; the child practises different training types with progress per type. | child, parents |

| UR-13 | The child sees only training types and content that fit their Klasse, grouped by school subject; trainers say which Klasse a list is for. | child, parents |
| UR-14 | Practising is rewarded: the child works towards something visible (new jerseys) through practice, never through speed or by comparison with others. | child |

All are "must" except UR-10 ("should").
